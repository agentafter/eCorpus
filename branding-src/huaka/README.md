# Logos originales de Huaka Digital

SVG originales del logotipo (`logo-full*`) y el isotipo (`logo-sm*`) en color, blanco y negro, tal como se entregaron (viewBox con margen).

Marca de Huaka Digital: **no** está bajo la licencia Apache-2.0 del repositorio.

No se sirven directamente: los de `branding/` son copias con el `viewBox` recortado (ver `branding/IMAGES.md`). La variante negra queda para usos futuros, como impresión o fondos claros monocromos.
